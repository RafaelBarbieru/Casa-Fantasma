# Casa Fantasma — notes for Claude

Point-and-click horror game built from pre-rendered art. **No engine, no runtime dependencies, no bundler.**
Vanilla ES modules plus raw WebGL1. Targets: itch.io (zip upload), self-hosting, and phone/tablet/desktop browsers.
Roles: the user owns the art and design and does not read the code, so optimise the code for my own maintenance, not for their reading.
The user-facing docs are in README.md; keep them in sync when workflows change.

## Hard constraints
- No game engine or framework. Small, self-written modules are fine. Prefer zero npm deps; if a build step is ever needed, use esbuild only.
- Every path must be **relative** (no leading `/`). itch.io serves the game from a CDN subpath.
- Paths are **case-sensitive** on itch.io and Linux hosts. `npm run build` checks the `src` paths in `data/*.json` for exact case.
- ES modules need HTTP, not `file://`. Use `npm run dev`.
- Mobile first: render on demand, cap DPR (`CONFIG.maxDpr`) and backbuffer width (`maxViewportW`). Handle touch through Pointer Events.
- GLSL ES 1.00 / WebGL1 only, so it runs everywhere. Item textures are padded to POT so mipmaps work.

## Art pipeline (as delivered)
The user said "GLB", but they actually deliver **pre-rendered WebP**:
- Flat `art-src/`, named by kind: `doorNN`, `paintingNN`, `posterNN` (items, alpha, cropped; screen size = native px × `item.scale` × `slot.scale`), `wallNN`, `floorNN` (seamless POT tiling textures).
- No room backgrounds: the scene is 1920×1080 scene px (`CONFIG.sceneW/H`); FS_BG tiles the wall above `room.floorLine` and draws the floor in perspective below it.
Sources (png/jpg -> lossy q90 WebP, webp copied as-is) -> `tools/images.mjs` -> `assets/<name>.webp`. Data files reference the generated `assets/...webp` paths.
Do not add a 3D runtime unless the user explicitly asks for one.

## Audio pipeline
- Masters are `audio-src/**/*.wav|ogg|mp3|flac` (the user delivers .ogg sfx), tracked with LFS and never shipped.
- `tools/audio.mjs` (runs from the predev, predev:lan and prebuild hooks) uses ffmpeg to write `assets/audio/**/<name>.ogg` (Opus) and `<name>.m4a` (AAC).
  - It is incremental (by mtime), deletes orphaned outputs, and preserves the channel count (mono or stereo, >2 downmixed).
  - It also writes `assets/audio/index.json` (all sound names, rewritten only on change), which the runtime uses to resolve prefixes.
  - Bitrates are in `RATES`: Opus 64k mono / 112k stereo, AAC 96k / 160k. Sample rate is 48 kHz.
- `src/audio.js` `audioUrl(name)` returns a URL for ONE format, chosen with `canPlayType` (Opus preferred).
  - SFX: `CONFIG.sfx` maps role -> `{ files: prefix, preload?, volume? }`. `src/sfx.js` `initSfx()` resolves the prefix against index.json (pool), decodes per `preload` ('all' at boot | 'one' = one decoded at a time, swapped after each play | 'none' = lazy). `playRole(role, delay)` picks at random without immediate repeats. `game.onSfx(role, delay)` -> `playRole`. Roles: door, locked, painting (slips), fall (painting falls + cracks), posterScratch, posterTear (last scratch), item (key/pills taken), levelEnd, levelStart (on the start-overlay tap and in `startLevel`), flashlight, ghostSpotted, heartbeatSlow/Fast, screamer (death, sfx/screamer_long), screamerShort (screamer room), lightSwitch (uses sfx/flashlight), healed (pill taken).
  - Long ambience/music should stream through an `<audio>` element plus MediaElementSource, because decoded PCM costs ~23 MB per stereo minute (a mobile memory risk).
  - Level ambience: `CONFIG.ambience.loops` and `.random.pool` are name PREFIXES resolved via index.json (`ambienceLoops()` / `ambiencePool()` in ambience.js). `generateWorld` picks `world.ambience` from the loops (seeded, last, so layouts don't shift), excluding `avoidAmbience` = the previous level's loop (main.startLevel passes it). `src/ambience.js` `setLevelAmbience(world)` -> `audio.playLoop()`: ONE reused `<audio loop>` element -> MediaElementSource -> GainNode (fades; reuse keeps iOS unlocked). Requests before the gesture are queued and start in `unlockAudio()`.
  - Random one-shots: `CONFIG.ambience.random` (pool, gapS, firstDelayS, chance, volume), decoded with the SFX at boot, setTimeout chain, Math.random (not seeded), no immediate repeats, skipped while hidden. The tab going hidden suspends the context and pauses the bed.
  - Decode during loading or room transitions, not mid-interaction.

src/rng.js          mulberry32
src/assets.js       loadDB (data/*.json), loadImage, makeSprite (POT pad + alpha hit mask)
src/debug.js        overlay (` key or ?debug): seed, room contents (targets/locks/keys), key locations, fps, slot markers; N = new world, K = all keys, B = start room, A = ambience one-shot
data/items.json     { id: { src, scale, depth, placement:[tags], kind? } }   tags: "door" | "wall" (paintings + posters); kind "poster" = tears
data/rooms.json     layouts { id: { slots:[{ id, x, y?, anchor?:'floor', scale?, accepts:[tags] }] } }   (x, y = item center, scene px). "doors" + "gallery"
data/ghosts.json    { ghosts: { id: { src, scale } }, screamers: { id: { src } } }   ghosts load as sprites (same Map as items)

tools/images.mjs    art-src/** -> assets/**/*.webp via ffmpeg libwebp (incremental, orphan cleanup, never touches assets/audio/). `LOSSLESS` names (ghost*) skip lossy: near-black detail dies otherwise

## Rendering model
- PS1 mode (`CONFIG.ps1.enabled`): everything below renders into a low-res FBO (`ps1.width` x 16:9, NEAREST), then `FS_POST` draws it to the letterbox with nearest upscale + `colorBits` quantize using a 4x4 Bayer dither in low-res pixel space. Rects and the beam are snapped to low-res pixels (`ps1.snap`). The scene shaders' noise dither is off in this mode (`uNoise`).
- Floor-anchored items (`slot.anchor: 'floor'`, i.e. doors) sit with their bottom on the floor line; FS_ITEM's `uClip` cuts glow + shadow below the sprite's bottom edge. Wall items are clamped to `floorY - room.wallMargin` in `Game.enterRoom`.
- One draw for the background (blending off; wall + floor textures on units 0/1, REPEAT + mipmaps, both sampled outside any branch), then one draw per item (premultiplied, `ONE, ONE_MINUS_SRC_ALPHA`), then the HUD canvas (`FS_HUD`, texture re-uploaded only when `hud.version` changes).
- Item shader, all in one pass:
  - sprite × light;
  - drop shadow = alpha sampled at `uv - offset` with mip bias (blur), drawn only outside the sprite;
  - outer glow = alpha at a high mip bias, outside the sprite, added on top.
- Shadow offset = `(itemCenter - (beam + handOffset)) * depth * perDepth`, clamped to `maxOffset`. It is computed per frame in `game.frame()`.
- Hit test uses the per-pixel alpha mask in native sprite px. Touch also samples 8 points at `touchSlop`.
- The loop runs only while `game.update()` returns busy (light easing, transition, glow) or while debug is on. Input and resize call `wake()`.
- The letterbox is "contain" at 16:9. Portrait on touch devices shows a rotate hint.

## World generation (maze, one world per level)
- Seed comes from `?seed=N`, or is random; `?level=N` (default 1). The game logs `[casa] level N seed S`.
- Rooms form a tree (rooms[0] = start, 3 doors). Door rooms have 2-3 doors; painting rooms 1-4 paintings. "Back" = parent.
- Per level: grow the open region (stage 0) -> master door (key 0, `to: EXIT`) on a free stage-0 door -> `sideLocks[level-1]` side doors (keys 1..n, regions at stage k) -> side keys hidden in stage 0, master key in stage 0 or (masterBehindChance) in one side region ("vault", rooted at a painting room) -> leftover doors become decoy painting rooms. `grow()` guarantees the free doors and paintings the locks and keys need. Always solvable.
- Each lock gets door art reserved for it (unique in the level), so the key's HUD thumbnail names its door (gold = master). No art repeats within a room.
- Explored glow: `Game.isExplored(room)` = every painting searched and every door unlocked (if locked), not EXIT, leading to an explored room (recursive over the tree). `markExplored()` sets `item.explored` on room entry and after a search; `frame()` then uses `CONFIG.glow.explored` (dull, no pulse).
- Using a key consumes it. The master door plays levelEnd, fades (winOutS), shows "Level N+1" (winHoldS, a tap skips it), then `main.startLevel(seed+1, level+1)` builds a NEW world (fresh inventory, start room has no back) and plays levelStart. Debug: N = new seed same level, L = next level.
- Each room also gets `wall`/`floor` (seeded, picked after its items); the wall always differs from the parent room's.
- Seed 42, level 1: room 0 doors -> rooms 3, 1, 2; the master key is behind painting01 in room 2; the master door (door07) is in room 5 (0 -> 3 -> 5). Room 7 (0 -> 3 -> 5 -> 7, lit) has poster01 + poster05.
- Headless check: import world.js + game.js in Node with stub sprites (full masks), tap item centres, step update(0.05). Game has no DOM deps.
- `?debug` exposes `window.casa = { game, renderer, assets, db }` for console poking (e.g. `casa.game.die()`).
- In an occluded/automated Chrome tab rAF runs ~2 fps and dt is capped at 0.05, so transitions take ~10x longer there.

## Dark rooms
- world.js: `room.dark = { switchAt, screamer? }` from `CONFIG.darkRooms` on its own rng (`seed ^ 0xda4c0de`, 3 draws per room), after pills, so layouts never shift. Any room but 0 and ghost rooms. Screamer = dark painting room with no key/pill -> `items: []`.
- game.js: entering an unlit dark room -> `killLamp(true)` (same flashlight cue as a ghost room). `lampT` drives the flashlight dying (`dying()`) for ghosts too. `room.sw` = switch item (invisible in the dark: only its hover glow shows; `makeSwitch`: free wall spot at `switchY` rows, picked by switchAt; it has `.lightSwitch`). `inDark()`: `hit()` returns only switch/back/pill. `turnOnLight()` -> `lit` set, `switchT` -> `ceiling` (flickerIn; × dying(ghost.t) with a ghost). Screamer room -> `jump = { img, t }` (t starts at -screamerDelayS), overlay via `screamerOverlay()` (keeps image aspect, shared with death), input blocked while it runs.
- Renderer: `frame.light.room = [x, y, reach, amount]` -> `uRoomLight`/`uRoomLightP` term added in `lightAt()`. Shadows come from the ceiling light when it's stronger than the flashlight.
- `isExplored(dark room)` needs it lit. Debug panel lists dark rooms (`!` = screamer).

## Paintings + loot
- First tap on a painting -> `Game.movePainting`: it slips (pose 'tilt': hangs from the top nail opposite `side`, swings `side * tiltDeg`, slides down until the loot is uncovered) or falls (pose 'fall', `fallChance`, or when the tilt would reach the floor): lowest corner at floorLine + floorSink, cracks on impact. Math.random, not seeded.
- Pose = `{ kind, side, px, py, dx, dy, ang, crack? }` (rotate around pivot, then shift; `toWorld`/`toLocal` in game.js). Kept in `game.poses` (uid -> pose) so re-entering shows it moved. `_maskAt` hit-tests through the pose.
- Loot = key/master_key/health sprite (`lootId(e)`) on the wall near the painting's top on `side` (`makeLoot`), in `room.loot`, drawn before the items, hit-tested first, tap -> `takeLoot` (keys/pills, sfx item, `game.taken`). `isExplored` needs it taken.
- Renderer: item `rot: [ang, pivotX, pivotY]` (VS `uRot`, all programs share VS, default 0) and `crack: [u, v, amount, seed]` (FS_ITEM procedural rays, `uCrackP`). Sprites carry `box` = tight alpha bounds (assets.makeSprite).

## Posters
- Wall art with `kind: 'poster'` (items.json). world.js treats them as paintings (same "wall" tag, keys/pills behind them); only game.js differs. Adding them changed seed dressing (art/walls), not the room graph.
- Tap -> `Game.scratchPoster`: first tap rolls the rip (`makeRip`, Math.random, kept in `game.rips` uid -> R): `hp/max` (CONFIG.posters.scratches), start point `sx, sy` on the art box edge, `dmax`, `reach` (= 1 - leftover, raised so the loot is always uncovered by then), loot spot `lu, lv` + `need` (grid search for the threshold closest to a random `lootAt` share). Loot is pushed to `room.loot` then (`makePosterLoot` -> shared `placeLoot`).
- Tear threshold `tearOf(R) = reach * (1 - hp/max)`; `it.tear` animates toward it (tearS). Field = distance from the start point / dmax (`tearAt`, box coords), + value noise in the shader. `_maskAt` drops torn pixels (no noise); `coveredLoot(it)` blocks hit-testing loot until `it.tear >= need`.
- hp 0 -> `searched` (dull explored glow), sfx posterTear; otherwise posterScratch.
- Renderer: item `tear: [[sx, sy, thr, seed], box uv rect, [aspect, dmax, jagged, rim]]` -> FS_ITEM `uTear*` (cuts sprite, shadow and glow; pale rim `uTearC` = CONFIG.posters.paper).

## Ghosts + health
- Ghost rooms (`kind: 'ghost'`, from `ghost.roomChance[level]`) are made from leftover dead-end doors in world.js (>= 1 per level when the chance > 0 and a leftover exists): `items: []`, no surfaces (bg null = black), fixed `ghost: { id, x, y }`. `isExplored(ghost room)` = visited.
- Random ghosts: `Game.enterRoom` schedules `spawnAt` (wall-clock ms, exponential with `randomPerMin[level]` + `graceS`; never in room 0 or ghost rooms). main.js sets a setTimeout to wake() the sleeping loop at spawnAt. Leaving a room with a random ghost stores it in `lingering` (room -> goneAt, `lingerS`); re-entering before goneAt re-summons it. Math.random, not seeded.
- `summon()`: plays flashlight sfx; update(): `lamp` flickers then 0 (`exposure * lamp`), ghost alpha fades after `G.delay` over `G.fadeIn` (rolled per summon from the `fadeDelayS`/`fadeInS` [min, max] ranges; plays ghostSpotted), `health -= drainPerS*dt`. While a ghost is present hover is suppressed except the back arrow (no door glow).
- Ghost draw: FS_ITEM `uFx = [selfLit, opacity, gain, additive]`; additive output alpha 0, so the opaque black PNG background is invisible.
- Pills: `CONFIG.pills.perLevel` (expected count: floor + fractional chance) placed in world.js on keyless paintings (`item.pill`) with a SEPARATE rng (`seed ^ 0x50111e5`), after dressing, so pills never shift layouts. `game.pills` persists across levels (main resets it with health on death). HUD icon = `data/items.json` "health" sprite (placement [], so never placed) at `CONFIG.hud.pills`; `hit()` returns 'pill' (allowed while a ghost is present) -> `usePill()`: health += `pills.heal` (of full), cap 1, sfx `healed`. Debug P = +1 pill.
- Health HUD: `hudState().health` (quantized, null when dead/end) + main adds `pulse` = `beatEnvelope()` (quantized; the loop stays busy while > 0, heartbeat calls wake() per beat). `Hud.health()`: red radial vignette below `heartbeat.start` + `data/items.json` "heart" sprite (bottom left, `CONFIG.healthHud`), lost rows drawn from a cached grey copy, beat = scale + 'lighter' flush. Beat timing: `heartbeat.thumps[role]` = [[offsetS, strength]] measured from the wavs.
- health <= 0: `die()` -> phase 'dead', screamer image as `frame.overlay` (pHud quad, flashing/jitter), screamer sfx; after `screamer.holdS` `onDeath` -> main restarts level 1 (new seed, health 1). Health persists across levels.
